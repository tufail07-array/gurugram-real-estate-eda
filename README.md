# Gurugram Real Estate Market Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Gurugram real estate dataset using Python.

The analysis focuses on understanding property prices, property characteristics, localities, BHK configurations, construction status, and other factors related to the real estate market.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis

The project includes:

- Data cleaning and preprocessing
- Data type conversion
- Text data cleaning
- Duplicate removal
- Group-wise analysis
- Property price analysis
- Locality analysis
- BHK analysis
- Price-per-square-foot analysis
- Data visualization

## Key Questions

The analysis investigates different aspects of the Gurugram real estate market, including:

- Property prices across localities
- Price per square foot
- Relationship between area and price
- BHK-wise property prices
- RERA approval and property prices
- Property type and pricing
- Construction status and pricing

## Visualizations

Matplotlib and Seaborn are used to visualize relationships and patterns in the dataset.
